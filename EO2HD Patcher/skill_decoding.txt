 Skill data all follows the same basic structure. Here's one example.

 {
      "skillName":            string, Japanese name. For example, "SWORDMAN  ＨＰブースト" = Landsknecht HP Boost.
      "skillNo":              Unique skill ID number.
      "skillMaxLevel": 10,    Self-explanatory.
      "skill_pattern": 10,                Unknown currently.
      "need_parts": 0,        Parts used, if any. Head = 1, Arm = 2, Leg = 3
      "use_masterly": [                   Unknown currently.
        0,
        0
      ],
      "trg_area": 0,                      Area it effects. 0 = single target, 5 = self-target.
      "trg_side": 0,                      Side of the field targeted. 0 = party, 1 = enemy.
      "use_scene": 0,                     Graphics scene, presumably?
      "ud_efficacy_type": 0,              No idea.
      "ud_efficacy_afbit": 0,             No idea.
      "bit": 0,                           No idea.
      "typeValue": [                      Generally understood.
        {
          "type": 51,                     No idea what this is, but...
          "value": [                      These are the numbers behind the scenes
            102,                          for each level, as an int representing a %.
            104,                          So, for example, at level 3, this boosts
            107,                          the character's HP by 107%.
            110,
            114,
            121,
            126,
            131,
            137,
            145
          ]
        }
      ]
    }
    Some of these values have many different entries:
        use_masterly (an array of two potential Mastery skills to use for prereqs.)
          1: Axes
          2: Swords
          3: Bows
          4: Shields
          5: Whips

        bit (is a bitmask of uncertain size - at least 8 bytes?)
             results below are currently with the individual bits.
          bit 0: This skill interacts with Cut damage
          bit 1: This skill interacts with Bash damage
          bit 2: This skill interacts with Stab damage
          bit 3: This skill interacts with Fire damage
          bit 4: This skill interacts with Ice damage
          bit 5: This skill interacts with Volt damage
          bit 6: This skill interacts with Head Bind
          bit 7: This skill interacts with Arm Bind
          bit 8: This skill interacts with Leg Bind
          bit 9: This skill interacts with Instant Death
          bit 10: This skill interacts with Petrification
          bit 11: This skill interacts with Sleep
          bit 12: This skill interacts with Paralysis?
          bit 15: This skill interacts with Poison
          bit 21: This skill reacts to an attack against it?
        typeValue.type
          1: TP cost
          2: Skill damage percentage
          3: action speed multiplier
          4: Skill accuracy
          8: % chance of activation
          9: % reduction of odds for future activations
          14: # of steps an effect is active for
          18: Affliction Rate for ailments
          19: Poison Base Damage
          101: (enemy to-hit reduction %)
